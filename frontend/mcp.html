MCP

Bingus no seu agente

O Bingus fala MCP, o protocolo que os agentes de IA usam para chamar ferramentas. Conecte uma vez e a sua IA passa a buscar na internet brasileira por conta própria: em português, com foco em tech, e lendo a página inteira quando precisa.

O endereço

É um servidor MCP remoto, por HTTP (streamable HTTP). Não instala nada: o cliente só precisa desta URL.

MCP_URL

Conectar

No terminal:

claude mcp add --transport http bingus MCP_URL

Com --scope user ele vale em todos os projetos, não só no atual. Confira com claude mcp list ou /mcp dentro do Claude Code.

No app do Claude (desktop ou web), como conector personalizado:

  1. Abra Configurações › Conectores.
  2. Clique em Adicionar conector personalizado.
  3. Nome Bingus e, na URL, o endereço abaixo.
  4. Numa conversa, ligue o Bingus no menu de ferramentas.
MCP_URL

Em ~/.cursor/mcp.json para todos os projetos, ou .cursor/mcp.json só para um:

mcp.json
{
  "mcpServers": {
    "bingus": {
      "url": "MCP_URL"
    }
  }
}

Em .vscode/mcp.json no projeto, ou pelo comando MCP: Add Server, escolhendo HTTP:

.vscode/mcp.json
{
  "servers": {
    "bingus": {
      "type": "http",
      "url": "MCP_URL"
    }
  }
}

As ferramentas aparecem no modo agente do Copilot Chat.

Em ~/.codex/config.toml:

config.toml
[mcp_servers.bingus]
url = "MCP_URL"

Qualquer cliente que aceite MCP remoto por HTTP: aponte para o endereço e pronto. Cliente que só sabe rodar servidor local (stdio) usa a ponte mcp-remote, que precisa do Node:

{
  "mcpServers": {
    "bingus": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "MCP_URL"]
    }
  }
}

O que a IA ganha

Duas ferramentas. O agente decide sozinho quando usar cada uma.

search(query, limit)

Busca no índice do Bingus, híbrida: palavras e significado. Devolve título, URL, data de publicação e um trecho de cada resultado, até 20 por vez.

read_page(url, question)

Lê uma página inteira, sem menus nem propaganda. Funciona até com URL fora do índice, buscada na hora. Com question, responde sobre a página.

Para testar, peça ao agente algo como “procure no Bingus como configurar o WireGuard no Ubuntu e resuma o passo a passo”.

Se pedir chave

Uma instância fechada responde 401 sem chave. Mande no header Authorization: Bearer SUA_CHAVE; no Claude Code, acrescente --header "Authorization: Bearer SUA_CHAVE" ao comando. Cliente que não deixa configurar header aceita a chave na própria URL:

MCP_URL?key=SUA_CHAVE

Sem MCP

A busca também responde no formato JSON do SearXNG. Open WebUI, LangChain e afins que já sabem falar com um SearXNG funcionam apontando para o Bingus:

API_URL/search?q=placa+de+video&format=json
